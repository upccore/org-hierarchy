# org-hierarchy

Консольное приложение: загружает оргструктуру (офисы, отделы, сотрудники)
из JSON в PostgreSQL и по id сотрудника выводит всех сотрудников его офиса.

```
$ python app.py find 3
Офис: Офис в Санкт-Петербурге
Сотрудники:
  Иванов
  Сидоров
  Петров
```

## Запуск

Нужны Python 3.10+ и Docker (или свой PostgreSQL 9.6+).

```bash
docker compose up -d --wait
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py import data.json
python app.py find 3
```

По умолчанию приложение подключается к базе из `docker-compose.yml`. Чтобы
использовать другую, задайте `DATABASE_URL`:

```bash
export DATABASE_URL=postgresql://user:password@host:5432/dbname
```

Команды:

- `python app.py import <файл.json>` - создать таблицу, если её нет, и
  загрузить в неё данные из файла (старые данные удаляются);
- `python app.py find <id>` - вывести офис сотрудника и всех его коллег.

Если что-то пошло не так, программа пишет ошибку и завершается с кодом 1
(неверные данные или id), 2 (неверные аргументы командной строки) или
3 (проблема с базой).

## Как это работает

Данные хранятся в одной таблице `org_unit` в том же виде, что и в JSON:
у каждой записи есть `parent_id` - ссылка на родителя. Схема лежит в
`sql/schema.sql`.

При импорте файл сначала целиком проверяется: все поля на месте, типы
правильные, id не повторяются, родители существуют, сотрудники лежат в
отделах, а отделы - в офисах, циклов нет. Только после этого данные
записываются в базу одной транзакцией.

Поиск - это один SQL-запрос с двумя рекурсивными CTE: первый поднимается от
сотрудника вверх до офиса, второй спускается от офиса по всем отделам и
собирает сотрудников. Глубина вложенности может быть любой - например,
в Москве есть отдел внутри отдела.

ORM не используется, только `psycopg2`. Про скорость запроса и варианты
оптимизации - в [COMPLEXITY.md](COMPLEXITY.md).

## Структура

```
app.py                  точка входа
org_hierarchy/
    cli.py              команды import и find
    db.py               подключение к базе
    importer.py         чтение и проверка JSON, загрузка в базу
    colleagues.py       поиск сотрудников офиса
sql/schema.sql          схема таблицы
sql/create_test_db.sql  создание тестовой базы (выполняется docker-compose)
data.json               данные из задания
tests/test_app.py       тесты
```

## Тесты

```bash
docker compose up -d --wait
python -m pytest
```

Тесты работают с отдельной базой `org_hierarchy_test`, которую создаёт
docker-compose, так что основные данные они не трогают. Другую тестовую базу
можно указать через `TEST_DATABASE_URL`.
